MinCap - The Legend of Zelda: The Minish Cap, native for Linux

1. Make the AppImage executable: chmod +x MinCap-*-Linux-x64.AppImage
2. Run it. Click "Choose ROM..." and pick your own dump of The Legend of Zelda: The Minish Cap (USA).
   MinCap checks the file and remembers where it is. It never copies or uploads it.
3. Settings (F1) > Game > Shortcut adds an applications-menu or Desktop entry that starts the
   game directly.

Settings, saves and save states are kept in:
  ~/.local/share/MinCap/MinCap/

MinCap does not include any game, BIOS, artwork, fonts or music from Nintendo.
